# JS-HTML-CSS-Modern Hesap Makinesi

## 📝 Proje Açıklaması

Bu proje, HTML, CSS ve JavaScript kullanarak modern bir hesap makinesi oluşturmayı gösterir. Temel matematiksel işlemleri gerçekleştiren, şık tasarımlı bir hesap makinesidir.

## 🎯 Özellikler

- ✅ Temel matematiksel işlemler (Toplama, Çıkarma, Çarpma, Bölme)
- ✅ Modern ve şık kullanıcı arayüzü
- ✅ Büyük ve okunması kolay ekran
- ✅ Temizle ve sıfırla fonksiyonları
- ✅ Responsive tasarım
- ✅ Ondalık sayı desteği
- ✅ Hata yönetimi

## 🛠️ Teknolojiler

- **HTML5** - Sayfa yapısı ve düğmeler
- **CSS3** - Modern tasarım ve animasyonlar
- **JavaScript** - Hesaplama mantığı

## 📂 Dosya Yapısı

```
JS-HTML-CSS-Modern Hesap Makinesi/
├── index.html      # Hesap makinesi arayüzü
├── style.css       # CSS stilleri ve tasarım
└── script.js       # Hesaplama fonksiyonları
```

## 🚀 Kullanım

1. ZIP dosyasını çıkartın
2. `index.html` dosyasını tarayıcıda açın
3. Sayıları ve işleçleri tıklayarak hesap yapın
4. "=" düğmesine tıklayarak sonucu görün
5. "C" veya "AC" ile ekranı temizleyin

## 💡 Öğrenme Amacı

Bu proje şunları öğretir:
- JavaScript ile matematiksel işlemler
- DOM manipülasyonu ve event handling
- String ve sayı dönüşümleri
- Hata yönetimi ve validasyon
- CSS ile arayüz tasarımı

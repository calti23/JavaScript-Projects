# JS-Gerçek Zamanlı Chat Arayüzü

## 📝 Proje Açıklaması

Bu proje, JavaScript kullanarak gerçek zamanlı bir chat arayüzü oluşturmayı gösterir. Kullanıcılar mesaj gönderebilir ve alabilir, animasyonlar ve modern tasarım ile kullanıcı deneyimi artırılmıştır.

## 🎯 Özellikler

- ✅ Gerçek zamanlı mesaj gönderme ve alma
- ✅ Modern ve responsive arayüz tasarımı
- ✅ Mesaj geçmişi görüntüleme
- ✅ Kullanıcı dostu deneyim
- ✅ HTML/CSS ile stillendirilmiş arayüz

## 🛠️ Teknolojiler

- **JavaScript** - İstemci taraflı mantık
- **HTML** - Sayfa yapısı
- **CSS** - Tasarım ve stillendirme

## 📂 Dosya Yapısı

```
JS-Gerçek Zamanlı Chat Arayüzü/
├── index.html      # Ana HTML dosyası
├── style.css       # CSS stilleri
└── script.js       # JavaScript mantığı
```

## 🚀 Kullanım

1. ZIP dosyasını çıkartın
2. `index.html` dosyasını tarayıcıda açın
3. Chat arayüzünde mesaj yazıp gönderin

## 💡 Öğrenme Amacı

Bu proje şunları öğretir:
- DOM manipülasyonu
- Event handling
- Real-time veri işleme
- Responsive tasarım

## 📌 Notlar

- Proje eğitim amaçlıdır
- Gerçek zamanlı iletişim için WebSocket veya Server-Sent Events kullanılabilir

# JS-Weather Forecast Project

## 📋 Proje Açıklaması

**JS-Weather Forecast Project**, JavaScript kullanılarak geliştirilmiş bir hava durumu tahmin uygulamasıdır. Bu proje, gerçek zamanlı hava durumu verilerini göstermek ve kullanıcılara çeşitli lokasyonlar için hava tahminleri sunmak amacıyla oluşturulmuştur.

## 🎯 Proje Özellikleri

- **Hava Durumu Verileri**: Güncel hava durumu bilgilerini gösterir
- **Şehir Arama**: Farklı şehirler için hava tahminleri sorgulayabilirsiniz
- **Grafik Arayüz**: Kullanıcı dostu web arayüzü
- **Responsive Tasarım**: Farklı cihazlarda düzgün görüntülenir

## 🛠️ Teknolojiler

- **JavaScript**: Ana programlama dili
- **HTML5**: Yapı ve bileşenler
- **CSS3**: Stilizasyon ve tasarım
- **API İntegrasyonu**: Hava durumu verilerini almak için

## 📦 İçindekiler

Zip dosyası içinde şunlar yer almaktadır:

- `index.html` - Ana HTML sayfası
- `style.css` - Stil dosyası
- `script.js` - JavaScript kodu
- `assets/` - Görseller ve kaynaklar

## 🚀 Kullanım

1. Zip dosyasını açın
2. `index.html` dosyasını tarayıcıda açın
3. Şehir adını girerek hava durumunu sorgulayın

## 💡 Özel Notlar

Bu proje, JavaScript ile harici API'lerle çalışmayı ve asenkron işlemleri öğrenmek için harika bir örnektir.

## 📝 Lisans

Bu proje açık kaynak olarak paylaşılmıştır.

# JS-HTML-CSS-Web Tabanlı Terminal

## 📝 Proje Açıklaması

Bu proje, HTML, CSS ve JavaScript kullanarak tarayıcıda çalışan bir terminal emülatörü oluşturmayı gösterir. Komut satırı arayüzüne benzer bir deneyim sağlayan web tabanlı bir terminal uygulamasıdır.

## 🎯 Özellikler

- ✅ Terminal benzeri komut arayüzü
- ✅ Komut girişi ve çıktısı
- ✅ Komut geçmişi (Yukarı/Aşağı tuşları)
- ✅ Klasik terminal tasarımı
- ✅ Metin tabanlı etkileşim
- ✅ Responsive arayüz
- ✅ Komut otomatik tamamlama özellikleri

## 🛠️ Teknolojiler

- **HTML5** - Sayfa yapısı ve komut girişi
- **CSS3** - Terminal tasarımı ve animasyonlar
- **JavaScript** - Komut işleme ve mantık

## 📂 Dosya Yapısı

```
JS-HTML-CSS-Web Tabanlı Terminal/
├── index.html      # Terminal arayüzü
├── style.css       # Terminal tasarımı ve stilleri
└── script.js       # Komut işleme fonksiyonları
```

## 🚀 Kullanım

1. ZIP dosyasını çıkartın
2. `index.html` dosyasını tarayıcıda açın
3. Komut satırına komut yazın
4. Enter tuşuna basarak komutu çalıştırın
5. Çıktıyı terminal ekranında görüntüleyin

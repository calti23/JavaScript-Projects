# JS-HTML-CSS-AI Chat Interface

## 📝 Proje Açıklaması

Bu proje, HTML, CSS ve JavaScript kullanarak yapay zeka tabanlı bir sohbet arayüzü oluşturmayı gösterir. Modern tasarım ve kullanıcı dostu arayüz ile AI benzeri bir chatbot deneyimi sağlar.

## 🎯 Özellikler

- ✅ AI benzeri sohbet arayüzü
- ✅ Modern ve profesyonel tasarım
- ✅ Responsive mobil tasarım
- ✅ Mesaj geçmişi depolama
- ✅ Yazma animasyonları
- ✅ Kullanıcı ve bot mesajlarının görsel ayırımı

## 🛠️ Teknolojiler

- **HTML5** - Sayfa yapısı
- **CSS3** - Modern tasarım ve animasyonlar
- **JavaScript** - İnteraktif işlevler

## 📂 Dosya Yapısı

```
JS-HTML-CSS-AI Chat Interface/
├── index.html      # Ana HTML dosyası
├── style.css       # CSS stilleri ve animasyonlar
└── script.js       # JavaScript fonksiyonları
```

## 🚀 Kullanım

1. ZIP dosyasını çıkartın
2. `index.html` dosyasını modern bir tarayıcıda açın
3. Sohbet arayüzüne mesaj yazın ve gönderme düğmesini tıklayın

## 💡 Öğrenme Amacı

Bu proje şunları öğretir:
- DOM manipülasyonu ve event handling
- CSS animasyonları ve transitions
- Responsive tasarım prensipleri
- Kullanıcı arayüzü tasarımı en iyi uygulamaları

## 🔧 Geliştirme Önerileri

- Gerçek bir API ile entegrasyon
- Yerel depolama (localStorage) eklemesi
- Daha fazla animasyon ve etkileşim
- Emoji desteği eklenmesi

## 📌 Notlar

- Gerçek AI işlevselliği için bir API entegrasyonu gereklidir

# JS-HTML-CSS-Döviz Kuru Çevirici

## 📝 Proje Açıklaması

Bu proje, HTML, CSS ve JavaScript kullanarak gerçek döviz kuru çevirişi yapan bir uygulamadır. Kullanıcılar para birimi seçerek anlık döviz kuru dönüşümünü yapabilir.

## 🎯 Özellikler

- ✅ Çeşitli para birimlerini destekler
- ✅ Gerçek zamanlı döviz kuru dönüşümü
- ✅ Modern ve temiz arayüz tasarımı
- ✅ Hızlı hesaplama
- ✅ Responsive tasarım (mobil uyumlu)
- ✅ İnteraktif dropdown menüler

## 🛠️ Teknolojiler

- **HTML5** - Sayfa yapısı
- **CSS3** - Tasarım ve responsive özellikler
- **JavaScript** - Dönüşüm hesaplamaları ve işlevler

## 📂 Dosya Yapısı

```
JS-HTML-CSS-Döviz Kuru Çevirici/
├── index.html      # Ana HTML dosyası
├── style.css       # CSS stilleri
└── script.js       # Döviz kuru hesaplama fonksiyonları
```

## 🚀 Kullanım

1. ZIP dosyasını çıkartın
2. `index.html` dosyasını tarayıcıda açın
3. Miktar girin
4. Kaynak para birimini seçin
5. Hedef para birimini seçin
6. Dönüştürülen miktar otomatik olarak görüntülenecektir

## 💡 Öğrenme Amacı

Bu proje şunları öğretir:
- JavaScript ile matematiksel işlemler
- DOM manipülasyonu
- Event listeners kullanımı
- Form girdilerini işleme
- Dinamik hesaplama yapı

## 🔧 Geliştirme Önerileri

- Gerçek API ile döviz kuru güncellemesi
- Geçmiş çevirişlerin kaydedilmesi
- Daha fazla para birimi desteği
- Grafik gösterimler

## 📌 Notlar

- Proje eğitim amaçlıdır
- Gerçek döviz kuru verileri için bir API kullanabilirsiniz
